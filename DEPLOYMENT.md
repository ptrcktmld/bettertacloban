# BetterTacloban Deployment

## Target

Cloudflare Pages with Git integration.

- Repository: `ptrcktmld/bettertacloban`
- Production branch: `main`
- Framework preset: None / static site
- Build command: `npm run build -- --no-bump`
- Build output: `dist`
- Root directory: repository root
- Custom domain: `bettertacloban.org`

No environment variables are required for the static-site build.

## Preview workflow

`setup/bettertacloban-v0.1` → Cloudflare Pages preview → QA → Pull Request → `main` → production

Use preview deployments to validate verified civic sections and the explicit verification placeholders before merging to `main`.

## Safety rules

Do **not** use inherited BetterBaguio AWS deployment infrastructure.

Do **not** run inherited PRISM synchronization.

Do **not** use inherited BetterBaguio AWS certificates, buckets, aliases, profiles, or domain configuration.

The `dist/` directory is the only publishable build output. It is generated by the build and should not be committed.

## Cloudflare configuration notes

`_headers` is generated into `dist/` and supplies conservative security and cache headers. HTML, civic JSON, the manifest, and service worker revalidate for freshness. CSS and JavaScript use moderate revalidating cache periods; image and font assets use a longer cache period.

No Content-Security-Policy is enabled yet. Before adding one, verify every active runtime origin and test the production build in a Cloudflare Pages preview.

No repository-level redirect is configured. Configure a `www` redirect only after both hostnames are intentionally attached to the Pages project and its behavior is verified.
