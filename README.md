# BetterTacloban.org

BetterTacloban.org is an independent, volunteer-built civic project for Tacloban City, Philippines. It aims to help residents find and understand public information while directing official transactions and records to the appropriate government sources.

BetterTacloban.org is **not an official City Government of Tacloban website**. Official government portals, publications, and records remain the source of truth. This project is currently under development.

## Project lineage

This project is being developed from the open-source [BetterBaguio](https://github.com/ashier/betterbaguio) civic website. BetterBaguio was itself adapted from [BetterSolano](https://github.com/BetterSolano/bettersolano).

Existing license terms, copyright notices, and attribution requirements must be preserved. See [LICENSE](LICENSE) for this repository's license.

The inherited repository contains Baguio-oriented material. No Baguio factual data should be treated as applicable to Tacloban. Every Tacloban-specific claim must be researched and verified independently before publication.

## Run locally

Install dependencies:

```bash
npm install
```

Start the local development server:

```bash
npm run dev
```

Then open [http://localhost:8000](http://localhost:8000).

## Research sources

Prefer authoritative, primary sources, including:

- City Government of Tacloban
- Tacloban City Council / Sangguniang Panlungsod ng Tacloban
- Philippine Statistics Authority (PSA)
- Commission on Audit (COA)
- Department of Budget and Management (DBM)
- Department of the Interior and Local Government (DILG)
- Department of Public Works and Highways (DPWH)
- Philippine Government Electronic Procurement System (PhilGEPS)
- Other official government agencies, legal repositories, and public records

## Content rules

1. Prefer primary sources.
2. Record the source URL and verification date for every fact that may change.
3. Never copy or infer another local government unit's facts, fees, requirements, records, or services for Tacloban.
4. Link to official government systems for transactions and authoritative records.
5. Clearly label BetterTacloban.org as independent and volunteer-built.
6. Exclude or clearly withhold inherited content until it has been verified for Tacloban.
7. Correct errors transparently and update the supporting source record.
